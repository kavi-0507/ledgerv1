# Ledger

A simpler personal finance app for students. See [the user journey](USER-JOURNEY.md) for the redesign decisions and [GitHub Pages setup](GITHUB-PAGES.md) for deployment.

Start with a labelled example month, then sign in to your own private account. Import bank CSVs, check uncertain categories, adjust a monthly spending plan, and track rent and bills with linked payment history.

Run `npm ci`, `npm run dev`, `npm test`, and `npm run build`. The build produces a static `out/` directory for GitHub Pages. Supabase setup is described in GITHUB-PAGES.md.
